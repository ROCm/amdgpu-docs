**************************************************************************************
Compatibility matrix
**************************************************************************************

The AMD GPU Driver (amdgpu) 31.20.0 is compatible with ROCm 7.12.0. For more information, see `ROCm 7.12.0 compatibility matrix
<https://rocm-stg.amd.com/en/docs-7.12.0/compatibility/compatibility-matrix.html>`__.

====================================
Operating system and kernel version
====================================

See `Operating system support <https://rocm-stg.amd.com/en/docs-7.12.0/about/release-notes.html#operating-system-support>`_ for ROCm supported operating systems and their kernel versions.

============
GPU support
============

See `Hardware support <https://rocm-stg.amd.com/en/docs-7.12.0/about/release-notes.html#hardware-support>`_ for the list of supported AMD Instinct™, Radeon™ PRO, Radeon, and Ryzen™ AI GPUs.
